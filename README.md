# Palette Studio

A responsive, dependency-free color palette generator built with HTML, CSS, and vanilla JavaScript.

## Features
- Generate palettes and shuffle unlocked colors
- Lock individual colors while generating the rest
- Copy HEX values by clicking a swatch
- Add colors (up to 10)
- Save/load/delete palettes using browser localStorage
- Export the current palette as a `.txt` file
- Light/dark mode, responsive layout, and keyboard shortcut (`Space`)

## Run locally
Open `index.html` in a modern browser. For best clipboard support, use a local development server such as VS Code Live Server.

## Files
- `index.html` — page structure
- `style.css` — responsive styling and themes
- `script.js` — palette logic and saved palettes
